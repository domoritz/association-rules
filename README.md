## About

An interactive explainer for the seminal data mining paper:

> Agrawal, R., Imieliński, T., & Swami, A. (1993). *Mining association rules between sets of items in large databases.* ACM SIGMOD Record, 22(2), 207-216.

## What's Covered

- What association rules are and why they matter
- Key concepts: support, confidence, and lift
- Interactive rule builder to explore metrics
- Step-by-step Apriori algorithm visualization
- Item co-occurrence network
- Real-world applications
